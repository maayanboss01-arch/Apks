Aayan APKs - GitHub Pages

1. Put app icons inside the icons folder.
2. Upload large APK files through GitHub Releases.
3. Edit apps.js to add each APK's name, icon, version, size, description and download link.
4. Edit script.js and replace PASTE_YOUR_YOUTUBE_CHANNEL_URL_HERE with your YouTube channel URL.

The Verify button checks only whether the website Subscribe button was clicked.
It does NOT check the visitor's actual YouTube subscription.

Download counters use GitHub Release asset download_count and refresh every 60 seconds.

Only distribute APKs you are legally allowed to distribute.
